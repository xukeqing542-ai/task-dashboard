# 徐苛清｜RIGHT TEC 跨境广告与经营分析作品

为跨境电商运营管培生、财务专员两个岗位分别制作的个人练习。**所有广告、商品、订单和财务数据均由脚本生成。未获得 Facebook 广告账户、公司店铺或财务系统权限；没有真实投放、成交或报表编制经历。** 视频为无品牌、无实物的原创文字分镜样片，不是已投放广告。

## 复现

使用 Python 3 标准库运行 `python ads_case.py` 与 `python finance_case.py`，分别得到 `ads_output/` 和 `finance_output/` 下的源数据、汇总表和 `summary.json`。本地压缩包另含两份可编辑 Excel：广告受众素材复盘、跨境经营日月报及 VLOOKUP 差异核对；还有 `creative_storyboard.py`、四张画面与 8 秒竖屏样片，视频生成需要 Pillow 和 ffmpeg。

## 两个岗位的项目证据

| 模块 | 输出 | 解释限制 |
|---|---|---|
| 受众、创意和账户监控练习 | 3 组受众 × 2 款创意 × 7 天的 42 行数据；按受众与素材输出 CTR、CVR、CPC、CPA、ROAS | 使用预设概率模拟，没有真实广告账户和投放效果 |
| 预算／素材迭代 | 对比假设贡献毛利率 40% 对应的盈亏平衡 ROAS 2.50，列出小额复核、暂停与归因检查项 | ROAS 大于 2.5 只说明案例中的广告前贡献覆盖广告费，不证明实投可盈利 |
| 竖屏广告创意样片 | 围绕家居收纳场景制作 8 秒英文文字分镜；问题、利益点、演示占位、行动引导四段 | 产品卖点与实物镜头需授权资料，不能宣称实际产品性能 |
| 财务日报／月报与经营看板 | 生成 360 行、30 天、3 平台、2 店铺、2 品类的核算案例，输出 30 份日报切片、3 平台月报和 12 格店铺品类矩阵 | 属于管理报表练习，不是企业财务报表或实际月结 |
| 数据口径与差异复盘 | 逐行比较业务导出表与净销售额重算，定位 3 条差异、合计 75 示例货币单位；保留异常清单及人工核对事项 | 差异被脚本人为植入；没有真实跨部门确认 |

## 职责对照

广告案覆盖受众和产品假设、创意及视频样片、账户结构与预算检查、CTR／CVR／ROAS 指标、素材复盘。财务案覆盖亚马逊／独立站／TikTok 日月报、源数据核验、品类和店铺矩阵、差异复盘与口径说明。

方法和数据可核验，但必须由本人能现场运行、解释假设、复核结果。具体品牌和投放策略仍需依正式业务资料与平台政策制定。
