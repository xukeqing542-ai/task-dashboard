# 亚马逊运营岗位练习｜需求与交付说明

这是独立完成的流程练习，全部订单、商品和 ERP 记录由本地脚本生成；没有登录卖家后台、接入企业 ERP 或操作真实订单。

## 跟岗位职责对应的交付

| JD 工作 | 本项目交付 | 仍需真实工作环境验证 |
|---|---|---|
| Listing 资料和内容优化 | 逐项检查 12 个演示 SKU，标记 6 条短标题／适配字段缺口；对待完善项写出英文标题和卖点草案。适配信息缺失时保持待核验，不编造适配车型。 | 正式商品规格、品牌词、图片授权、平台校验、上架成功 |
| 市场及竞品、定价 | 计算演示商品成本、平台费及运费下的单位毛利与 5% 降价情景；另备关键词／竞品观察与 ACoS 测算方案。 | 真实竞品价格、广告支出、税费退货、平台费更新 |
| 订单、发货和 ERP | 120 行演示订单与 112 行物流记录、118 行 ERP 记录对账；输出 8 条待确认发货、2 条 ERP 缺失、4 条金额差异，逐单保留标记；部分订单可同时命中两项规则。 | 真实订单权限、发货 SLA、订单状态变化、ERP 操作与财务关账 |
| 平台规则和安全 | 交付前核对产品真实性、适配证据、禁止夸大宣传、图片使用授权；发货异常和账号通知需查阅当期卖家后台规则并升级处理。 | 正式平台培训、当期政策条款、账号健康考核 |
| 销售和流量 | 对 4,000 条演示访客按渠道和 A/B 组汇总转化，观察差异的区间跨零，避免把差异写作已证实提升。 | 广告后台、自然流量、真实订单归因、真实销售提升 |

## 使用方法

在此目录运行 `python run_case.py`，再运行 `python amazon_ops_case.py`。后者读取前者生成的 Listing 表并输出 `output/amazon_ops/` 下的原始表、逐单对账、英文 Listing 草案与汇总。两脚本均只用 Python 标准库；删除输出目录后重跑应得到相同数量和金额。

对账标记是需要人工确认的待办，不等于实际物流延迟、店铺处罚或财务错账。所有示例指标仅用于展示操作思路。
