# 徐苛清｜跨境电商运营（亚马逊方向）作品

个人练习：英文 Listing 字段核验与草案、演示 SKU 定价毛利、模拟订单与发货／ERP 对账、合成访客按渠道的转化分析。**没有登录亚马逊卖家后台，也没有处理企业订单或实际 ERP。**

## 运行

下载此分支的 ZIP 并在根目录执行：

```bash
python amazon-case/run_case.py
python amazon-case/amazon_ops_case.py
```

只需 Python 标准库。脚本在 `amazon-case/output/` 生成访客、分渠道数据、12 个演示 SKU 的审核结果及汇总；第二段脚本生成 `amazon-case/output/amazon_ops/` 的逐单对账表、英文 Listing 草案和汇总。

## 交付和核验

| 工作 | 可核验结果 |
|---|---|
| Listing | 12 条 SKU 中 6 条需完善标题或适配字段；对其中 6 条形成英文草案，缺车型依据的 3 条保持待核验。 |
| 订单与 ERP | 120 条订单、112 条发货记录、118 条 ERP 记录；8 条待核发货、2 条 ERP 缺失、4 条金额差异，合并后 12 条订单需人工复核。 |
| 渠道与实验 | 4,000 条合成访客，A/B 组 4.30% 对 4.25%；差异置信区间跨零，不宣称提升。 |
| 定价 | 对 12 个演示 SKU 计算基础毛利与 5% 降价后的毛利，成本和费用均是情景假设。 |
